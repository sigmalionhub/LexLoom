# Contributors

This project was built by the four of us. The commit history does not show that. The code
was committed into this repository by one person, so every commit carries a single name —
it records who committed the code here, not who wrote it. GitHub's contributors graph is
derived from that history and inherits the same limitation.

The design was settled together before the work started, the decisions were argued out
together as it went, and every commit was read by the rest of us before it moved. Any of us
can speak to any part of it.

All of us work at [sigmalion.io](https://sigmalion.io).

- [**Alex Kutsiy**](https://github.com/Corvin89)
- [**Sergey Korkishko**](https://github.com/Spiritvoin)
- [**Roman Polshikov**](https://github.com/polshikovrm)
- [**Eugeny Silin**](https://github.com/eugenysilin)

The planning and the reviews were conversations, not pull requests, so none of this can be
verified from the repository the way the rest of this project asks to be verified. It is
stated on the same terms it was given. Commits from here on carry `Co-authored-by:`
trailers, which do leave a trace.
